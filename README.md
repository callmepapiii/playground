# 🐉 Cryptid Explorer API

A **toy FastAPI project** that tracks legendary creatures (cryptids) and the daring explorers who study them.  
Built to practice layered architecture, SQLite databases, and clean Git workflows.

## 🎯 What It Does

- Stores cryptids (like Godzilla, Bigfoot, Nessie) and explorers in a local SQLite database.
- Exposes a simple REST API to read data.
- Separates code into **web** (FastAPI routes), **service** (business logic), and **data** (database access) layers.

## 🧱 Tech Stack

| Layer       | Technology             |
|-------------|------------------------|
| API framework | FastAPI               |
| Server       | Uvicorn                |
| Database     | SQLite                 |
| Language     | Python 3.10+           |
